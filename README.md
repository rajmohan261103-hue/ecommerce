# Dataset instructions

1. Open the [UCI Online Retail II dataset page](https://archive.ics.uci.edu/dataset/502/online+retail+ii).
2. Download `online_retail_II.xlsx`.
3. Place the workbook in this folder.

Expected filename:

```text
online_retail_II.xlsx
```

The original workbook is not committed to this repository because it is approximately 43.5 MB. Download it directly from UCI and retain the dataset citation in the main README.

Source: Chen, D. (2012). *Online Retail II* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D
